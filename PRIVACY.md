# LeetSensei Privacy Policy

Last updated: 2026-08-30

LeetSensei is a browser extension for explaining and reviewing LeetCode problems.

## Data processed

- The extension reads the current LeetCode problem and, when you request a review, code from the LeetCode editor.
- Your API key and model preference are stored in Chrome extension storage on your device.
- When you request an AI feature, the relevant problem text, code, prompts, and settings are sent directly to the provider you selected: OpenRouter or Google AI Studio. Those providers process the request under their own policies and terms.
- The extension does not operate a developer server, sell user data, run advertising profiles, or collect analytics.

## Your choices

You can remove your API key from the extension settings or uninstall the extension. Do not enter credentials or content you do not want to send to the selected AI provider.

## Limited use

Data is used only to provide the extension's described AI assistance. It is not sold, used for personalized advertising, or transferred for an unrelated purpose. The extension follows the Chrome Web Store User Data Policy, including its Limited Use requirements.

Publishers should replace this line with a monitored support email before submitting the extension.
